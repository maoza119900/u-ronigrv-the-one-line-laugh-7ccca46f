A tiny deterministic program that writes one funny line — a single sentence of at most 200 characters — to `entry.txt`, entered in make.fun's "The One-Line Laugh" bounty. The line is an everyday developer truth with the twist at the end: green tests on the first try, one tiny celebratory change, everything broken.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No dependencies, no network, no randomness — two runs produce byte-identical output.
